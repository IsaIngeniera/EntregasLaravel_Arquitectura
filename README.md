# EntregasLaravel_Arquitectura

Repositorio creado para subir los proyectos y entregas correspondientes a la materia **Arquitectura de Software**, Universidad **EAFIT**.

## Actividad 01

### Tutorial 01
En esta actividad se realizó la creación de una página web desde cero utilizando el framework **Laravel**, cubriendo los siguientes elementos:

- Creación del proyecto Laravel mediante Composer.
- Definición de rutas (`web.php`).
- Creación de controladores (`HomeController`, `ProductController`).
- Construcción de vistas con Blade, incluyendo un layout base con navbar.
- Envío de datos dinámicos desde el controlador hacia las vistas.
- Validación de formularios (creación de productos).
- Estilos personalizados con CSS.
